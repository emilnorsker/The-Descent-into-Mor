# Combat Conditions and States

## Environmental States

1. **Oiled**
   ```
   Basic Effect:
   - Slippery footing
   - Highly flammable
   - Hard to grip
   
   Influence:
   - Catches fire easily
   - Makes weapons slip
   - Ruins grip on armor
   ```

2. **Ablaze**
   ```
   Basic Effect:
   - Searing pain
   - Smoke inhalation
   - Spreads to surroundings
   
   Influence:
   - Causes panic
   - Destroys equipment
   - Others avoid you
   ```

3. **Mud-Covered**
   ```
   Basic Effect:
   - Heavy movement
   - Reduced visibility
   - Slick surface
   
   Influence:
   - Weapons less effective
   - Armor weighs more
   - Better camouflage
   ```

4. **Wet**
   ```
   Basic Effect:
   - Reduced movement speed
   - Increased physical resistance
   - Causes gradual damage
   ```

5. **Alcohol-Soaked**
   ```
   Basic Effect:
   - Reduced movement speed
   - Increased physical resistance
   - Causes gradual damage
   ```

## Combat States

1. **Bleeding**
   ```
   Basic Effect:
   - Blood loss
   - Leaves traces
   - Growing weaker
   
   Influence:
   - Attracts predators
   - Makes ground slippery
   - Harder to concentrate
   ```

2. **Winded**
   ```
   Basic Effect:
   - Heavy breathing
   - Slower reactions
   - Need to recover
   
   Influence:
   - Easier to hit
   - Must catch breath
   - Vision narrows
   ```

3. **Dazed**
   ```
   Basic Effect:
   - Poor balance
   - Blurred vision
   - Slow reactions
   
   Influence:
   - May fall over
   - Easy to disarm
   - Can't dodge well
   ```

## Positional Advantages

1. **High Ground**
   ```
   Natural Advantage:
   - Better leverage
   - Easier defense
   - Control space below
   
   Risk:
   - Can be pulled down
   - Fall damage
   - Limited retreat
   ```

2. **Wall at Back**
   ```
   Natural Advantage:
   - Can't be flanked
   - Solid brace point
   - Clear front arc
   
   Risk:
   - Limited movement
   - Can be cornered
   - No retreat path
   ```

3. **Flanking Position**
   ```
   Natural Advantage:
   - Hard to defend against
   - Better attack angles
   - Force movement
   
   Risk:
   - Exposed position
   - Can be countered
   - May be baited
   ```

## Natural Combinations

### Terrain Interactions
```
Mud + High Ground:
- Slope becomes treacherous
- Can cause slides
- Natural defense

Oiled + Wall:
- Can't brace properly
- Weapons might slip
- Armor less effective

Ablaze + Cornered:
- Panic likely
- Must move
- Smoke builds up
```

### Combat Situations
```
Bleeding + Winded:
- Growing faint
- Must rest soon
- Easy target

Dazed + Flanked:
- Very vulnerable
- Can't track threats
- Likely to fall

Mud + Bleeding:
- Trail hidden
- Harder to move
- Ground dangerous
```

### Position Effects
```
High Ground + Rain:
- Slope treacherous
- Poor visibility
- Advantage reduced

Wall + Surrounded:
- Last stand
- No escape
- Time limited

Flanking + Rough Ground:
- Footing crucial
- Slower approach
- Risk/reward
```

## Environmental Factors
```
Rain:
- Ground slickens
- Vision reduced
- Metal slippery

Darkness:
- Hidden movement
- Surprise likely
- Distance unclear

Confined Space:
- Limited swings
- Close quarters
- Echo effects
```

## Tactical Considerations
```
Defensive:
1. Use terrain for cover
2. Control space with reach
3. Watch footing always

Offensive:
1. Force bad positions
2. Create environmental threats
3. Cut off strong positions
```
